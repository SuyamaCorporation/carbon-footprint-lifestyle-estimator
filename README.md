# ライフスタイル別カーボンフットプリント推定

交通・食事・電力・購買習慣を入力して年間CO2排出量を推定し、日本平均との比較と削減シミュレーションを表示。

## 機能

- カテゴリ別入力フォーム（交通・食事・電力/ガス・購買）
- 各カテゴリのCO2排出係数をハードコードして年間排出量（tCO2e）計算
- 日本平均（約9.5t/年）との比較棒グラフ
- 削減策クリックで削減効果シミュレーション
- localStorageで設定を自動保存

## 排出係数（主要）

- 自動車: 0.000132 t-CO2e/km
- 電力: 0.000434 t-CO2e/kWh（日本平均）
- 牛肉: 0.0068 t-CO2e/食
- 飛行機: 0.255 t-CO2e/時間

## 技術仕様

- バニラJS / Tailwind CDN
- XSSガード: escHtml関数によるユーザー入力のサニタイズ
- レスポンシブ対応 / アクセシビリティ: aria-label付与済み
